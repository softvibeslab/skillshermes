# Resort Leadership Example

## Pattern

A useful specialization pattern that emerged in session:

- Primary executive skill: answers where the operation is leaking.
- Companion flow skill: answers where the leader is leaking focus, time, and attention.
- Profile SOUL/orchestrator: names both explicitly so they are reachable in live use.

## Example Framing

### Operational layer
Question:
- Where is the operation leaking?

Scope:
- routines of leadership
- metrics across marketing, sales, and operations
- manager follow-up
- meeting prep
- diagnostics
- decision memory
- executive writing outputs
- daily prioritization

Typical deliverables:
- daily briefing
- attention radar
- weekly summary
- executive minute
- action plan
- follow-up note

### Flow layer
Question:
- Where is the leader leaking flow?

Core formula:
- routine work -> flow leak -> agent opportunity -> first simple action

Typical friction categories:
- information chasing
- repeated follow-ups
- manual coordination
- repeated recap/report work
- decision-prep overload
- supervision-heavy processes
- attention-breaking interruptions

Typical deliverables:
- Flow Friction Map
- Top 5 Flow Leaks
- Agent Opportunity Backlog
- Leader Flow Audit

## Why This Split Works

If both concerns are buried inside one skill, the agent tends to blur:

- business underperformance
- leader overload

Keeping them as paired skills makes the outputs cleaner:

- one skill says what deserves attention
- the other says what is stealing attention

## Design Lesson

When a user asks for a specialized executive agent, check whether the real need has two separate lenses:

1. business/operating intelligence
2. executive flow/friction intelligence

If yes, create an umbrella + companion pattern instead of forcing one monolithic skill.
