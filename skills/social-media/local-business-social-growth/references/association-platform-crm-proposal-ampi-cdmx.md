# Association Platform / CRM Proposal Pattern — AMPI CDMX

Session source: public analysis of `https://ampicdmx.org/` for adapting ROVI/COPIM work to another real-estate association.

## Public facts observed

- AMPI CDMX homepage positions the org as Asociación Mexicana de Profesionales Inmobiliarios Ciudad de México A.C.
- Navigation: Nosotros, Consejo, Directorio, Capacitación y eventos, Asociado AMPI, Beneficios, Requisitos, Revista Enlace Inmobiliario, Blog, Contacto, Ingresar.
- “¿Qué es AMPI?” says AMPI has 80+ national sections and that the CDMX section was constituted in 1980, bringing together 400+ important companies in the sector.
- Benefits page emphasizes prestige, special events, monthly working breakfasts, congress, year-end dinner, monthly training, property publication, representation, diplomas/certification, and office use.
- Requirements page lists manual document collection sent by email: application, experience, photo, address proof, fiscal docs, CURP, INE, CV, high-res logo.
- Public directory on `ampicdmx.thesmartflat.com/asesores-ampi-cdmx` exposed “108 Asesores verificados” at time of review.
- Properties portal and Smart Manager login are external to the main site.
- Event detail example: “7 errores que están saboteando tus cierres”, 2026-05-28 18:00, Zoom; payment link to WeChamber and registration link to Zoom.
- Contact emails visible: `ifernandez@ampicdmx.mx`, `mestrella@ampicdmx.mx`; phone `(55) 5511 4702`.

## Strategic interpretation

This is a strong fit for an association operating-system pitch, not a generic CRM pitch. The observable digital operation is fragmented across:

- institutional website,
- pre-registration/contact forms,
- manual email document intake,
- external directory,
- external properties portal,
- external login/Smart Manager,
- external event payment,
- external Zoom registration,
- magazine/blog/alliances.

Position the product as the connective layer that makes the association measurable and easier to operate.

## Recommended pitch framing

Do NOT lead with “we sell CRM.” Use:

> ROVI AMPI CDMX: the operating system to manage members, prospects, events, properties, payments, communications, sponsors, and board reporting from one connected workflow.

Human framing:

> ROVI does not replace AMPI’s identity or the tools already in use; it connects, orders, and measures the operation that currently lives across forms, email, WhatsApp, Zoom, payment links, directories, and external portals.

## Module map from COPIM/ROVI to real-estate associations

- COPIM members → AMPI associates / advisors / agencies.
- COPIM association admin → AMPI board/operations roles.
- Membership payments → dues, renewals, event fees, sponsorships.
- Directory → verified advisor public profiles.
- Marketplace → property publication, services, allied benefits, sponsors.
- Control tower → board dashboard: active members, renewals, leads, events, payments, attendance.
- Knowledge agent → AI assistant for joining requirements, event FAQs, internal lookup, campaign copy, board reports.

## MVP demo flows

1. **Association prospect pipeline**
   - Website “Quiero asociarme” form creates a prospect.
   - Checklist generated from requirements.
   - Responsible assigned.
   - Automated WhatsApp/email reminders for missing documents.
   - Stages: Nuevo → Contactado → Documentos solicitados → Documentos recibidos → En revisión → Aprobado → Pago pendiente → Asociado activo.

2. **Event/capacitation workflow**
   - Event landing captures interest.
   - Payment status is tracked even if an external payment link remains in use.
   - Zoom/register link is tracked.
   - Reminder, attendance, no-show, survey, certificate, and post-event follow-up.
   - Metrics: interested, registered, paid, attended, no-show, conversion by source.

3. **Verified advisor directory**
   - Profile tied to membership status and documents.
   - Certifications, specialties, zones, properties, contact requests.
   - Lead attribution so association can prove member value.

4. **Board/control tower**
   - Active associates, new prospects, pending docs, renewals, payments, event attendance, property leads, sponsor pipeline.

## 30-day implementation outline

- Week 1: tenant, roles, pipelines, initial sample member/directory data.
- Week 2: pre-registration + digital dossier + document checklist.
- Week 3: event module + registration/payment tracking + reminders + attendance.
- Week 4: basic member portal + directory profile + board dashboard.

## Pitfalls

- Do not propose replacing existing external platforms immediately; that triggers resistance. Start as integration/measurement layer.
- Do not imply access to internal data. Label all findings as public-site observations.
- Do not scrape or use private member data without explicit permission.
- Avoid generic “CRM benefits”; anchor every module to observed public workflows: requisitos, eventos, directorio, propiedades, revista, aliados, login.
