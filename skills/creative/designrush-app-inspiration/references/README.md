# DesignRush App Inspiration

Hermes skill that researches current examples from:

https://www.designrush.com/best-designs/apps

It is intended to activate automatically for mobile app planning, design, implementation, redesign, and UI/UX review. It produces a short evidence-backed benchmark before selecting a direction, then pairs with `mobile-app-ui-design` and `ui-ux-pro-max`.

The skill does not copy designs. It extracts transferable patterns, records source URLs, distinguishes awards from featured/popular placement, and labels anything that could not be visually verified.
