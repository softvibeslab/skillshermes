Status vocabulary:

- **Defined:** role exists in durable documentation.
- **Configured:** runtime/channel configuration exists.
- **Recent activity observed:** dated logs or outputs exist.
- **Running now:** confirmed by a live process or end-to-end probe.
- **Legacy/duplicate probable:** inference; state the basis.

## One-sentence explanation

> We create specialized digital teammates that understand a business, use authorized tools, and turn requests into verifiable work while people retain sensitive decisions.

Adapt the nouns to the audience; keep the structure.

## Infographic structure

Recommended layouts: hub-spoke for a connected ecosystem, bento-grid for a portfolio overview.

- Center: the person and their goal.
- Ring 1: interaction channels.
- Ring 2: consolidated business lines.
- Ring 3: observable outputs.
- Footer: human approval boundary and CTA.

Avoid putting profile names in the headline. Use recognizable outcomes.

## 90-second video scaffold

### 0–15 seconds — problem

Show context switching, dropped follow-ups, and operational overload.

### 15–35 seconds — distinction

Explain that a chatbot answers while an agent occupies a role, uses tools, and produces evidence.

### 35–65 seconds — cases

Use 3–5 one-sentence cases across distinct business lines. Name the output, not merely the agent.

### 65–80 seconds — flow

Person → channel → project context → authorized tools → evidence → human approval.

### 80–90 seconds — close

Repeat one memorable promise and invite the viewer to a concrete demo.

## Five-minute demo scaffold

Use exactly two complementary cases.

For each:

1. Send a concrete request.
2. Show how project context changes the response.
3. Let the agent execute a real tool-backed action.
4. Reveal the artifact, test, report, or other evidence.
5. Stop at the approval boundary.

Never use private customer data in a public demo. Prepare sanitized fixtures.

## Lightweight landing page

1. Hero with one-sentence explanation and short video.
2. Chatbot vs agent comparison.
3. Five-step operating flow.
4. Visual map of business lines.
5. Three evidence-backed cases.
6. Approval and safety boundaries.
7. Replication method for the prospect’s market.
8. One CTA.

## Comprehension test

After consuming the kit, the viewer should answer without prompting:

1. What makes this different from a chatbot?
2. What concrete work can an agent perform?
3. What proof shows the work happened?
4. What remains under human control?
5. Which use case would you pilot first, and why?

Failure on any question means simplify the message; do not add another deliverable.

## Content expansion order

Once the kit works:

1. Record case interviews.
2. Produce a short podcast season.
3. Derive clips, carousels, and infographics.
4. Instrument operations.
5. Publish a dashboard only after metrics are reliable.
