# Veo API generation and deterministic teaser fallback

Use this when turning an analyzed source video into a short cinematic concept and attempting Google Veo generation.

## Source analysis first

1. Probe the source with `ffprobe`.
2. Extract a contact sheet at regular intervals with `ffmpeg`.
3. Transcribe narration with `faster-whisper` or `mlx_whisper`.
4. Reduce the source to one transformation arc, not a feature list. A useful structure is:
   `pain/chaos -> guided action -> orchestration -> human decision -> brand close`.

## Discover the live model

Do not hardcode an assumed Veo version. Query `GET https://generativelanguage.googleapis.com/v1beta/models` and select a model whose name contains `veo` and supports `predictLongRunning`.

At generation time:

```text
POST /v1beta/models/{model}:predictLongRunning
{
  "instances": [{"prompt": "..."}],
  "parameters": {
    "aspectRatio": "16:9",
    "sampleCount": 1,
    "durationSeconds": 8,
    "resolution": "720p"
  }
}
```

Poll `GET /v1beta/{operation-name}` until `done: true`, then download the generated video URI using the same API credential.

Provider quirk: omit `personGeneration` unless the live model documentation explicitly supports the requested value. Veo 3.1 preview rejected `allow_adult` as an invalid argument.

## Prompt shape

A reliable short prompt specifies:

- one continuous visual transformation;
- camera movement and lens language;
- a small brand palette;
- exact audio progression and one short spoken line;
- negative guidance: no logos, readable text, subtitles, watermarks, malformed hands, or generic HUD clutter.

Avoid asking the video model to render key brand typography. Add titles deterministically in post.

## Quota/billing boundary

A model appearing in `models.list` does not mean the project has generation quota. Treat HTTP `429 RESOURCE_EXHAUSTED` as a billing/quota boundary, not a prompt error. Do not keep retrying or silently switch paid projects. Preserve the final prompt and operation settings so generation can resume after billing is enabled.

## Deliver something useful when Veo is blocked

Create a deterministic concept teaser from the source footage:

1. Pick 4–6 representative source moments.
2. Extract stills and animate them with `zoompan`.
3. Add darkening, brand-color accents, and concise title cards.
4. Add a short TTS narration and a minimal synthesized audio bed.
5. Render H.264/AAC with `+faststart` and verify duration, dimensions, streams, and file size with `ffprobe`.
6. Extract a final contact sheet and inspect text legibility and narrative order.

Do not claim this fallback was generated by Veo. Label it as a concept teaser and keep the Veo-ready prompt beside it.

## FFmpeg portability

Homebrew/minimal FFmpeg builds may omit `drawtext` and `subtitles`. Probe `ffmpeg -filters` before building the render command. If text filters are absent, render typography and overlays into source frames with Pillow, then animate those frames with FFmpeg. This preserves deterministic typography without reinstalling FFmpeg.
