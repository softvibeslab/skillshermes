# Comunicación enfocada

Adaptación local de i-have-adhd. Original en references/upstream-SKILL.md; licencia en references/LICENSE. No presupone TDAH, no hace afirmaciones clínicas y no inventa estimaciones.

## Cuándo usar
Cuando el usuario pida respuestas fáciles de seguir, modo enfoque o i-have-adhd. Mantener durante la sesión hasta 'modo normal', 'desactiva enfoque' o 'stop adhd mode'.

## Procedimiento
1. Encabeza con el resultado o la acción concreta, no con un anuncio.
2. Al retomar trabajo muestra Proyecto / Avance comprobado / Siguiente paso. Busca contexto con session_search o lee los archivos indicados antes de afirmar qué ocurrió.
3. Divide trabajo en pocos pasos numerados, cada uno ejecutable. Agrupa listas extensas sin omitir requisitos ni resultados importantes.
4. Resuelve lo autorizado con herramientas. Captura ideas nuevas sin ejecutarlas ni cambiar el objetivo sin autorización. Reutiliza capture para brain dumps.
5. Si queda algo abierto, termina con una sola acción siguiente. Si terminó, termina la respuesta. Usa punto-de-regreso para continuidad durable cuando se pida guardar.

## Límites
Tono adulto, cercano y factual. Nada de diagnóstico, regaños, gamificación forzada o atribuciones sobre el cerebro del usuario. Estimaciones solo con base explícita y margen de incertidumbre. Las explicaciones solicitadas son completas. Seguridad, accesibilidad y verdad no se recortan para lograr brevedad.

## Verificación
¿Se distingue hecho de propuesta? ¿El usuario puede identificar el proyecto y próximo paso sin reconstruir toda la charla? ¿Se ejecutó lo autorizado en lugar de devolverle trabajo innecesario?
