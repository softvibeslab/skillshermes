When a user shares a URL or image path, the skill asks for confirmation and then creates a Notion page (in a configured database) and an Obsidian note (in the configured vault).\nversion: 1.0.0\nauthor: hermes-agent\nlicense: MIT\nmetadata:\n  hermes:\n    tags: [Notion, Obsidian, workflow, link, image]\n---\n\n# Add Link/Image to Notion and Obsidian\n\nThis skill provides a simple interactive workflow:\n1. Receive a URL or image path (provided via context or argument).\n2. Ask the user for confirmation to save to both Notion and Obsidian.\n3. If confirmed:\n   - Create a Notion page in a specified database (database ID can be set via memory or prompted).\n   - Create an Obsidian note in the vault with markdown content that includes the link or embeds the image.\n\n## Prerequisites\n\n- Notion API key must be available as `NOTION_API_KEY` environment variable (already stored in memory).\n- Obsidian vault path must be known (environment variable `OBSIDIAN_VAULT_PATH` or default `~/Documents/Obsidian Vault`).\n- A Notion database where pages will be added. You can store its ID in memory as `NOTION_DEFAULT_DB_ID` or be prompted each time.\n\n## Usage\n\nFrom a Hermes agent conversation, you can invoke this skill by providing the link or image path in the context, e.g.,:\n\n```\ndelegate_task:\n  goal: \"Add the shared link to Notion and Obsidian\"\n  context: \"URL: https://example.com/article\"\n  skill: add-link-to-notion-obsidian\n```\n\nOr in a terminal/command line you could run the underlying script (see `scripts/add_link.sh`).\n\n## How it works\n\nThe skill relies on the `notion` and `obsidian` skills for the actual API calls and file operations.\n\n### Notion page creation\n\n- Uses the Notion API v2025-09-03.\n- The page is created as a child of the target database.\n- Properties set:\n  - `Name` (title): the URL or a description.\n  - `URL` (url): the shared link.\n  - `Added` (date): today's date.\n  - `Type` (select): \"Link\" or \"Image\" based on input.\n\n### Obsidian note creation\n\n- Creates a markdown file in the vault under a folder `Inbox` (or root if preferred).\n- Filename is sanitized from the URL or a timestamp.\n- Content includes:\n  - A heading with the URL or description.\n  - The link as a clickable markdown link.\n  - If the input is an image file path, an embed: `![Image](path)`.\n  - A timestamp of when it was added.\n\n## Customization\n\n- To change the Notion database, update the memory entry `NOTION_DEFAULT_DB_ID` or edit the script.\n- To change the Obsidian folder, modify the script constant `OBSIDIAN_FOLDER`.\n\n## Error handling\n\n- If the Notion API returns an error, the skill will output the error and stop.\n- If the vault path is not accessible, the skill will notify the user.\n\n---\n\n## Script Reference\n\nSee the linked script `scripts/add_link.sh` for the exact implementation.\n
